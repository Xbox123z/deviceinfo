# 设备信息 · 自研版

一个纯 Java 原生安卓应用，展示本机硬件/系统信息。**零第三方依赖**（不用 androidx / gradle），从零实现，不抄袭任何第三方代码。

## 功能（10 类卡片）

| 卡片 | 内容 |
|---|---|
| 🖥 设备 | 品牌/型号/设备名/制造商/构建指纹/Android 版本/API 级别/安全补丁/Build ID |
| ⚙️ CPU | ABI/核心数/各核当前频率/硬件名 |
| 💾 内存 | 总内存/可用/Java 堆 |
| 🗄 存储 | 内部总容量/可用/是否可移动 |
| 📺 屏幕 | 分辨率/密度 dpi/刷新率/HDR 能力 |
| 🔋 电池 | 电量/状态/温度/电压/健康度/充电类型 |
| 🌐 网络 | WiFi/移动网络/IP/运营商/MAC/DNS |
| 📡 传感器 | 全部传感器（名称+厂商+类型） |
| 📷 相机 | 前后摄像头数量与最高分辨率 |
| 📋 系统 | 开机时长/时区/语言/SELinux |

## 特性

- 🔄 **下拉/刷新按钮** 重新采集（自动每秒重采电池/频率）
- 📋 **长按数值** 复制
- 🌙 **深色主题**，原生 View，Material 风格卡片
- 📱 **minSdk 23**（Android 6.0）~ **target 33**（Android 13/14），所有 API 调用带 SDK 判空兜底，不会因缺 API 闪退
- 🔒 **纯本地**：无任何网络请求、无广告、无统计，不申请存储/通讯录/位置等无关权限

## 技术栈

- 纯 Java + 原生 View（不依赖 androidx）
- 构建：`aapt2` + `javac(source/target 8)` + `d8` + 签名，无 Gradle
- 签名：v1+v2 双签（自签名）

## 构建

```
aapt2 compile/link → javac → d8 → 注入 classes.dex → 签名
```

或直接下载 Release APK。

## 兼容性

在 Huawei CLS-AL00 (HarmonyOS 4.3 / Android 12) 实测安装运行正常。
